01 Sobre o serviço

O BotGram é uma ferramenta gratuita que gera código-fonte de bots do Telegram a partir de um formulário. O resultado é um arquivo bot.js que você baixa e executa por conta própria, na sua infraestrutura.

Nós não hospedamos, executamos nem operamos os bots gerados. A responsabilidade pelo funcionamento, hospedagem e manutenção do bot é inteiramente sua.

03 Token do Telegram

O token do seu bot é usado apenas para validar o formato junto à API do Telegram e para montar o código gerado. Ele não é armazenado em banco de dados nem compartilhado com terceiros.

Ainda assim, trate seu token como uma senha. Se suspeitar de vazamento, revogue e gere um novo pelo @BotFather.
