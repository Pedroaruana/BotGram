Política de Privacidade

RESUMO

Não pedimos cadastro, não coletamos e-mail e não usamos rastreadores de publicidade. O token do seu bot nunca é gravado. Os dados do formulário ficam em memória temporária no servidor e somem no primeiro reinício.

01 Quem somos

O BotGram é um projeto pessoal de portfólio mantido por Pedro Aruana. Não é uma empresa e não possui CNPJ. O contato para assuntos de privacidade é aruanapedro@gmail.com.

02 Dados que você fornece

Ao usar o configurador de bots, você preenche:

  • Nome e descrição do bot — usados para montar o código gerado
  • Produtos e preços — viram o menu do bot no código
  • Mensagens personalizadas — texto de boas-vindas e título do menu
  • Chave PIX — inserida no código gerado para você receber pagamentos
  • Token do Telegram — usado apenas para validação, nunca gravado

Ao clicar em gerar o código, esses dados (exceto o token) são enviados para a nossa API e guardados em memória volátil, sem banco de dados. Quando o servidor reinicia, tudo é perdido. Não há como recuperar configurações antigas.

03 Sobre o token do Telegram

O token é enviado à nossa API somente para consultar o endpoint getMe do Telegram e confirmar que o bot existe. A resposta retorna apenas o nome e o username público do bot.

O token não é salvo em memória, em disco ou em log. Ele existe apenas durante a requisição de validação e no código que você baixa para o seu computador.

04 Dados coletados automaticamente

A hospedagem do site (Vercel) e da API (Cloudflare Workers) registra dados técnicos de acesso por padrão, como endereço IP, tipo de navegador e horário da requisição. Esses logs pertencem a essas plataformas e são usados para segurança e prevenção de abuso.

Não temos ferramenta própria de analytics, pixel de rastreamento, heatmap ou qualquer script de publicidade.

05 Cookies e armazenamento local

O BotGram não usa cookies de rastreamento nem cookies de terceiros. Usamos apenas localStorage do seu navegador para guardar sua escolha sobre o aviso de cookies, para não mostrar o banner toda vez.

Esse dado fica somente no seu dispositivo e nunca é enviado para nenhum servidor. Você pode apagá-lo limpando os dados do site pelo navegador.

06 Compartilhamento com terceiros

Não vendemos nem compartilhamos seus dados. Os serviços envolvidos são apenas:

  • Vercel — hospedagem do site
  • Cloudflare Workers — hospedagem da API
  • API do Telegram — consultada só na validação do token

07 Seus direitos (LGPD)

A Lei Geral de Proteção de Dados garante a você o direito de confirmar o tratamento, acessar, corrigir, eliminar e obter portabilidade dos seus dados.

Como não mantemos cadastro nem banco de dados persistente, na prática não há dado pessoal armazenado para consultar ou excluir. Ainda assim, se tiver qualquer solicitação, escreva para aruanapedro@gmail.com.

08 Menores de idade

O BotGram não é direcionado a menores de 18 anos e não coleta intencionalmente dados de crianças e adolescentes.

09 Alterações nesta política

Esta política pode ser revisada a qualquer momento. A data da última atualização fica sempre no topo da página.
